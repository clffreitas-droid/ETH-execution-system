This repository contains:
A python code for ETH signal model creation.
A Python code for backtest
A base for an execution system that can simulate trading alive using websocket.
Data base for minute data on ETH for the system to run and backtest
An optimized deep learning model.
A scale model to transform data without future contamination.
Important to mention that this is still a working in progress. All the comments and documentations are far from ideal, and there are still many features to be tested and new ideas to be analysed.
